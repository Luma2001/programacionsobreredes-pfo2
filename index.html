Gestión de Tareas PFO 2

API REST con Flask, SQLite y Cliente de Consola

Ver / Clonar en GitHub

Endpoints de la API

POST /registro Registro con contraseña hasheada (SQLite)
POST /login Verificación segura contra hash almacenado
GET /tareas Pantalla HTML de bienvenida y confirmación de servicio

Cómo clonar y ejecutar el proyecto

# 1. Clonar el repositorio
git clone https://github.com/Luma2001/programacionsobreredes-pfo2


# 2. Instalar dependencias
python -m pip install flask requests

# 3. Iniciar el servidor API (Terminal 1)
python servidor.py

# 4. Iniciar el cliente de consola (Terminal 2)
python cliente.py
