Sistema de Gestión de Tareas PFO 2

Proyecto práctico de Programación en Redes: API REST con Flask, persistencia relacional en SQLite y cliente de consola.

Endpoints de la API

POST /registro: Recibe credenciales en JSON y almacena contraseñas hasheadas.

POST /login: Comprobación de credenciales mediante algoritmos de hash seguro.

GET /tareas: Vista HTML de bienvenida y confirmación de servicio activo.

Tecnologías Utilizadas

  • Flask: Microframework para endpoints REST.
  • Werkzeug Security: Hashing criptográfico irreversible.
  • SQLite: Motor de base de datos embebido sin servidor.
  • Requests: Cliente HTTP interactivo en consola.
